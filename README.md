# Pavethran's Data Science Portfolio

> One new data project every Sunday. Built from scratch with **Apify** (data) + **Excel** (cleaning) + **Tableau Public** (visualisation) + **GitHub** (code).

I'm a data-science learner publishing my work in public while job-hunting. Every week I pick one question about the data-science hiring market, scrape ~500 real job postings, analyse them, build a dashboard, and write up what I learned. By Week 8 there will be 8 projects here, all reproducible.

## Tools I use every week

- **Apify** — for scraping LinkedIn / Indeed / Glassdoor job postings reliably
- **Microsoft Excel** — pivot tables, formulas, light cleaning
- **Tableau Public Desktop** — one dashboard per week, all interactive online
- **GitHub Desktop** — version control without command-line headaches
- **LinkedIn** — Sunday morning post with the dashboard screenshot
